## 积分是什么

积分是 TapTap 制造的计量单位，用于 AI 对话和素材生成等云端与本地能力。余额、可用模型、有效期都在「我的积分」页面实时显示——不要凭记忆回答「我有多少积分」或「这个模型多少钱」。

## 五类积分

| 类型 | 来源 | 用途与限制 |
|---|---|---|
| 通用积分 | 平台/活动/购买等渠道发放 | 可用于全部支持模型与素材生成；是否可用还受当前模型与服务端校验影响 |
| 基础积分 | 平台发放（含会员商品发放） | 只能用于平台允许的部分对话模型和指定生图模型 |
| 活动积分 | 活动发放 | 可能带有效期，或绑定到具体项目 |
| 项目积分 | 仅对应项目（如 Game Jam、编辑精选、项目扶持） | 只能花在该项目上 |
| 付费积分 | 购买积分包获得 | 永久有效，多次购买累加；与其他可消耗积分用完后才被使用；与会员权益相互独立 |

会员是单次开通、不是自动续费；会员可能同时发放会员通用积分与基础积分，按商品规则分期或一次性生效，并随会员卡到期。订阅发放的积分不是永久付费积分。

积分不可提现、不可转赠、不可退款。

## 消耗顺序与可用性

当前消耗顺序：**活动积分 → 项目积分 → 基础积分**。

通用积分和付费积分是否可用，还受三件事影响：当前选中的模型、项目范围、服务端消费校验。所以「我有通用积分」不等于「这个模型一定能用通用积分」。

不要向用户承诺精确扣费金额；需要时让对方在「我的积分」页面看实际扣减，或先小额试跑一次再决定。

## 什么会消耗、什么不消耗

会消耗：

- AI 对话（按模型与 token 计费，长对话、反复重试都算）。
- 图片、视频、音频等素材生成；高分辨率、视频比图片贵。
- 本地 MCP 模式下调用的云端生成能力（本地不等于免费）。

不消耗：

- 浏览文档、看排行榜、浏览制造研究所。
- 发布面板的操作（物料生成、测试版更新、正式发布仍需等待任务执行，但面板操作本身不消耗创作积分）。

拿不准时：先回答「这一步会不会产生积分消耗」，把选择权交给用户。

## 成本红线（Agent 必须遵守）

1. **没有用户在对话中的明确要求，不调用消耗积分的生成工具。** 「帮我看看能不能做」不等于「帮我生成」。
2. **高消耗生成前先说明影响**：会生成什么、大概几张/几段、可能消耗哪类积分、有没有更省的替代（先用占位图、先做文字方案）。等用户确认。
3. **不自动替换、不默认选择模型或通道**。模型「自动」是平台当前默认，不是让你替他决定；换模型等于换价格与效果，属于用户的决定。
4. **一次只生成必要的东西**：先一张试风格，确认后再成套生成。
5. **不编造价格、额度、模型能力表**。文档没有的，回答「以页面显示为准」。

## 结果未知（uncertain）处理

生成类任务最贵的错误是「以为失败又重投一次」。用三态台账管理：

| 状态 | 含义 | 允许的动作 |
|---|---|---|
| inflight | 已提交，尚未拿到结果 | 只查询状态，不重投 |
| confirmed | 拿到任务 ID / 明确受理 | 轮询进度；失败按平台错误处理 |
| failed | 服务端明确拒收（4xx + 业务错误码） | 可安全重试或换通道 |
| uncertain | 传输层故障：超时、连接重置、fetch failed、无响应 | **禁止盲目重投**；先查询；确需重投要用户确认并说明可能已扣费 |

要点：

- 提交前先写台账（本地 JSON，原子写），记：时间、目标、参数摘要、幂等键、状态。
- 同一任务复用同一个幂等键，避免重复扣费。
- 轮询限流只提示「稍后再查」，不要把状态改成失败。
- 对用户表述要诚实：「提交结果未知，可能已扣费，我先查状态」优于「失败了，我再试一次」。

## 省积分的做法

- 先最小可玩：用几何体/纯色占位验证玩法，确认好玩再生成美术。
- 描述精确：用途、主体、构图、风格、配色、格式一次说清，减少重生成。
- 成套生成前先出一张样图，锁定风格。
- 复用素材：同一套 UI 元素、同一张 BGM 尽量复用；改需求前先想清楚。
- 一次一个结果：一条需求只改一件事，减少返工。
- 长对话及时收尾：同目标同对话，换方向新建对话，避免上下文越滚越贵。

## 常见问法与回答

| 用户问 | 回答要点 |
|---|---|
| 生成一张图要多少积分 | 文档没有固定价；与模型、质量、尺寸有关，以生成时页面显示和「我的积分」扣减为准 |
| 本地开发免费吗 | 不免费，云端能力照常计费 |
| 发布要花积分吗 | 发布面板操作不消耗创作积分；物料生成会消耗 |
| 我的积分快没了怎么办 | 去「我的积分」看余额与有效期；优先用活动/项目积分；减少生成、先做占位 |
| 任务卡住了能重投吗 | 先查状态；结果未知时禁止盲目重投，见上文 uncertain |
