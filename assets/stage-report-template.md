# 阶段报告模板

> 用法：每个阶段结束、进入下一阶段前发送。末尾必须是一句用户可以回答的确认请求；没确认不得继续。

## 阶段【0–5】：【阶段名】

### 1. 本阶段做了什么

- 【3–5 条，动词开头】

### 2. 产出物

- 【确认单 / 需求文本 / 验收记录 / 物料清单 / 脚本输出】

### 3. 验证结果

- 【已通过：…】
- 【未通过 / 有风险：…】
- 【积分消耗：本轮是否产生、是否已获授权】

### 4. 下一步与需要你确认的点

- 下一步：【进入阶段 X，做 Y】
- 需要确认：【具体问题，给选项】

> 确认后我继续；如果你要调整【某点】，告诉我，我改完再报告。

## 阶段报告纪律

- 不写「已完成」了事，要写清验证方式与结果。
- 有未通过项必须列出来，不能藏。
- 涉及积分消耗的，写明是否已获用户明确同意。
- 报告结尾必须是可回答的确认请求，不能是「我继续了」。
