# 首轮需求模板

> 用法：阶段 2 产出。把【】替换成确认单里的内容；一次只做最小可玩核心循环。发给 AI 前自己读一遍：能不能一句话说出「这轮只做什么」。

~~~text
做一个【横屏 / 竖屏】【2D / 3D】【玩法类型】小游戏，第一轮只要最小可玩版本。

玩法目标：【玩家做什么；怎样算成功；怎样算失败】
表现形式：【视角；画面方向；UI 主题 Astroon / BrawlForge / PixelForge；美术基调；首轮可用占位图形】
操作方式：【输入方式；核心动作；操作区域】
核心循环：【做 → 得到 → 变难/变强 → 再做】
首轮范围：【只做哪几屏、哪几个机制】

界面：
- 开始页：【标题 + 按钮】
- 游戏页：【HUD 显示什么；游戏区】
- 结束页：【分数 / 结果；重开按钮】

这一轮不做：【道具 / 音效 / 皮肤 / 排行榜 / 设置 / 多关卡 / 联网 / 剧情】

验收：
- 能正常开始，无报错；
- 【核心操作】跟手且有反馈；
- 成功 / 失败都能触发，结束页信息正确；
- 重开后状态清零；
- 目标方向下按钮、文字都清楚可点。
~~~

## 写作检查

- [ ] 一句话能说清这轮做什么
- [ ] 五要素齐全，没有「看情况」
- [ ] 有明确的「这一轮不做」
- [ ] 验收条目可以逐项勾选
- [ ] 已和用户确认主题与横竖屏
